This repository contains the master script and master spreadsheet for the paper by Ednie, Knudby, and Kerr, 2027. 
The paper is on the effect of spatial resolution of thermal data on the performance of established butterfly abundance and occurrence habitat use models.
The overheating index (OI) values per resolution were extracted from rasters created by the master script.
Other environmental values were previously extracted (see Ednie & Kerr, 2026) to establish the abundance and occurrence models.
Original thermal rasters are available upon request.
